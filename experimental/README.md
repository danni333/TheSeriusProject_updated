# experimental/

Moduli sperimentali e didattici, separati dal codice core in `src/`.
Non sono production-ready e non sono compilati di default: ogni modulo è
opt-in via flag CMake `SERIUS_EXPERIMENTAL_*` (dichirati nella root
`CMakeLists.txt`).

Documentazione completa: [`docs/experimental.md`](../docs/experimental.md).
